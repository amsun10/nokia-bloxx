# 经典诺基亚《摩天大楼》（Tower Bloxx）网页复刻版

怀旧复刻 2000 年代塞班/J2ME 经典手机神作 ——《摩天大楼》（Tower Bloxx）。

## 🎮 游戏特色

1. **经典诺基亚实体机身还原**
   - 带有经典磨砂质感的诺基亚机身外壳、顶部听筒与经典 NOKIA 标志。
   - 包含完整的 3x4 实体九宫格数字按键（带有凸点标记的 **5 号按键**）、五向导航键与功能软键，具备真实的物理按压反馈音效与动效。
   - 提供 **“📱 诺基亚机身”** 与 **“🖥️ 全屏模式”** 一键无缝切换。

2. **核心物理与玩法机制**
   - **摆动吊车（Crane Physics）**：基于摆动单摆动力学，伴随高空随机风力扰动。
   - **对齐评分（Combo System）**：
     - **PERFECT（完美对齐）**：大楼吸收晃动保持稳固，触发连击音阶奖励、欢呼入驻居民小人、烟花与额外人口。
     - **GOOD / OK（轻微偏移）**：由于偏心重力激发整座大楼发生真实的阻尼摆动晃动，楼层越高摆动越明显，考验预判下一块方块落点的平衡时机。
     - **MISS（严重脱靶）**：方块沿大楼侧边缘坠落翻滚，扣除 1 条生命（共 3 条生命）。
   - **高度视差与环境演进**：从地平线远景天际线、漂浮白云层、夕阳霞光直至深空星际与弯月。

3. **复古声音系统**
   - 基于现代 Web Audio API 的全套程序化 8-bit 合成音效引擎（下落破空声、重击落地声、Combo 连击和弦音阶、大楼形变嘎吱声、按键声与复古背景 BGM）。
   - 零外部音频依赖，完全离线免加载，100% 秒开即响。

4. **最高分纪录持久化**
   - 自动在本地存储中保存最高入住人口、最高楼层数与历史最高连击。

## 🕹️ 操作方式

| 操作按键 | 功能 |
| :--- | :--- |
| **空格键 (Space)** / **数字键 5** | 释放/掉落下落方块 |
| **手机实体按键 5** / **导航中心 OK 键** | 点击下落方块 |
| **直接点击 / 触控屏幕** | 掉落下落方块 |
| **M** / 右功能软键 | 切换静音 / 音效 |
| **B** | 切换背景音乐 (BGM) |
| **F** | 切换机身外壳 / 纯净全屏模式 |

## 🚀 启动与游玩

### 方法 1（推荐）
在 Windows 资源管理器中双击根目录下的 **`start.bat`**，将自动启动本地静态服务器并用默认浏览器打开 `http://localhost:8080`。

### 方法 2（命令行）
```bash
# 使用 Python 启动
python -m http.server 8080

# 或使用 Node.js npx
npx serve .
```
然后在浏览器中访问 [http://localhost:8080](http://localhost:8080) 即可开始盖楼！
